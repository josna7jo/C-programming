 Circle Calculator

This program calculates the area and surface area using the radius.

 Formulas

- Area = π × r²
- Surface Area = 4 × π × r²

Functions Used

- `printf()` – displays output
- `scanf()` – takes input
- `pow()` – calculates powers

 Header Files

- `stdio.h` – input and output
- `math.h` – mathematical function
