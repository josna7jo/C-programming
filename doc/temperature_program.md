TEMPERATURE CONVERSION PROGRAM
 In this program we will learn how to convert celsius to fahrenheit and viceversa
  

## FORMULAS
FAHRENHEIT = (celcius * 9/5)+ 32
CELSIUS =(fahrenheit-32) * 5/9

HERE, float is used because temperature can have decimal values.

## FUNCTIONS USED
 1. printf()- to display
 2. scanf()-to take input
